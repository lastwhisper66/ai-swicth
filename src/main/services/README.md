# 配置切换服务

在此协调目录解析、共通配置、完整预览、切换、备份、原子写入和恢复。路径设置保存配置目录，并兼容旧版文件路径。共通模板按工具加密保存，保存立即应用，切换供应商时复用完整模板；模板与工具配置一起备份及恢复。Codex 的 API Key、地址和模型统一存入 `config.toml`，仅访问这一个工具配置文件。预览在主进程脱敏后返回，不写入文件。

旧版多文件备份先完成正文完整性校验，再仅选取工具配置及当前应用对应的共通模板进行恢复，不读取或写入其他历史关联文件。旧 TOML 未包含密钥时提示重新应用已保存的供应商。

多文件写入需要失败恢复；开发时使用临时目录，只有用户发起应用供应商、保存并应用共通配置或恢复操作才修改真实工具配置。
