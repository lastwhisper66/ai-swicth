# 供应商配置

在此维护供应商数据模型、输入校验和本地存储。API Key 的读写只允许在主进程处理，提供给界面的列表数据默认脱敏。

列表和完整配置复用 `utils/api-key.ts` 的前后缀脱敏规则。只有用户点击编辑器眼睛时，主进程通过校验来源和供应商 ID 的 `providers:reveal-api-key` IPC 返回该供应商的完整密钥；不把明文加入普通快照。界面将读取值与修改草稿分开保存，只查看后保存继续使用 keep，用户编辑后才使用 replace。

存储正文版本为 2，沿用 `providers.v1.json` 文件名；旧单模型读取为有稳定 ID 的默认预设，下次保存升级。每个工具独立保存多个模型、默认模型、选项、Header 和连接能力，旧共用供应商保留两工具数据。`configuration-validation.ts` 严格校验列表、默认引用、选项、路由及请求头；Header 更新使用 keep / replace，删除通过移除对应记录表达，摘要不回传已保存的值。

Claude 模型的名称直接由模型名生成，模型 ID 以不含 `[1m]` 的形式配合 `context1m` 保存；输入后缀也会归一化。旧预设的思考强度、Fast 和自动压缩字段兼容读取但不再应用，下次显式保存供应商库时移除。思考强度改由共通模板管理，Codex 的显示名称与选项保持独立。
