# 供应商配置

在此维护供应商数据模型、输入校验和本地存储。API Key 的读写只允许在主进程处理，提供给界面的列表数据默认脱敏。

列表和完整配置复用 `utils/api-key.ts` 的前后缀脱敏规则。进入供应商编辑器时，主进程通过校验来源和供应商 ID 的 `providers:get-secrets` IPC 返回该供应商的 API Key 与各工具请求头值；不把这些值加入普通快照。API Key 载入密码输入框并默认隐藏，眼睛只切换显示方式；自定义请求头值使用普通文本输入框。界面将读取值与修改草稿分开保存，只查看后保存继续使用 keep，用户编辑后才使用 replace。载入期间禁用相关输入和保存，失败时可重试，退出编辑器后的异步响应不会更新表单。

供应商保存于 `ai-switch.db` 的供应商、工具连接、模型预设及 Header 关联表，不再读写 `providers.json`。供应商只按 `claude-code`、`codex` 保存，不区分本机或 WSL。每个工具保存多个模型、默认模型、选项、Header 和连接能力，供两个环境共同选用；旧共用供应商保留两工具数据。`configuration-validation.ts` 严格校验列表、默认引用、选项、路由及请求头；Header 更新使用 keep / replace，删除通过移除对应记录表达，摘要不回传已保存的值。云端导出仍采用无版本字段的可移植业务对象，存储结构不进入存档协议。

兼容正文 v1/v2 和旧云端记录：旧单模型使用稳定 ID 生成默认预设，WSL 专属记录映射到基础工具。同一条记录同时含有不同的本机/WSL 配置时，将 WSL 差异保留为带稳定 UUID 的“原 WSL”供应商；名称冲突添加迁移编号，不合并或丢弃凭据和选项。启动迁移时转换旧本地数据并备份原文，云端导入时先转换再整份覆盖；不写入真实工具配置。

模型预设只保存稳定记录 `id`、实际 API 模型 `model` 与 `options`，不再保存显示名称；默认引用与接管状态继续使用稳定记录 ID。旧库和旧备份中的模型 `name` 字段兼容读取后丢弃，新建、更新、预览与新导出不包含该字段。界面直接显示实际模型 ID，同一 ID 的不同预设由选项说明区分。

Claude 模型 ID 以不含 `[1m]` 的形式配合 `context1m` 保存，输入后缀也会归一化，展示和写入时恢复后缀。Claude 与 Codex 的主思考强度都由共通模板管理，不属于供应商模型预设；Codex 的计划模式思考强度和其他模型选项保持独立。
