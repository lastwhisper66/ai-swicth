# 本次配置字段清单

更新日期：2026-10-25。以下功能已接通，兼容条件和人工验证范围见 [实现与验收记录](tool-configuration-implementation.md)。完整方案见 [执行计划](tool-configuration-options.md)。

| 位置       | Claude Code                                  | Codex                                                        |
| ---------- | -------------------------------------------- | ------------------------------------------------------------ |
| 供应商连接 | 地址、API Key、自定义请求头                  | 地址、API Key、自定义请求头、Responses WebSocket 能力声明    |
| 模型列表   | 多个模型、默认模型，仅填写模型名             | 多个预设、默认预设、相同 API 模型的不同选项                  |
| 模型选项   | 1M 上下文复选框（添加或移除 `[1m]`）         | 1M、思考强度、Fast、计划模式思考强度、思考摘要、回复详细程度 |
| 模型路由   | 默认 Opus、Sonnet、Haiku、子代理模型         | 无                                                           |
| 共通思考   | low、medium、high、xhigh                     | 无                                                           |
| 共通搜索   | MCP Tool Search、Web Search / Web Fetch 权限 | Web Search（默认 / 禁用 / 缓存 / 实时）                      |
| 共通更新   | 无                                           | 启动时检查更新                                               |
| 共通署名   | 隐藏 AI 署名                                 | 无                                                           |
| 共通历史   | 无                                           | 历史文件大小（转换为 bytes）                                 |

- 保存供应商与应用预设是两个操作；应用组合该连接、所选预设和对应工具的共通模板。
- Codex 模型选项默认不写入。切回默认时恢复接管前值，原无值时清除本应用生成的覆盖。Claude 的 1M 勾选直接控制模型名后缀，不限制自定义别名；取消不强制降低模型原生容量。
- Claude 思考强度仅在共通配置设置，保存至 `effortLevel` 并同步当前模型的 `modelSettings` 条目，切换供应商或模型后沿用。不提供模型显示名称、Fast 或自动压缩控件；旧预设中的这三类选项不再应用，原有工具文件中的 Fast 和压缩字段保留。
- “隐藏 AI 署名”一个开关管理 commit、pr、sessionUrl，关闭后恢复原值。
- Header 值默认脱敏；编辑支持保留、替换和删除，不能把脱敏占位值写回配置。
- 表单和高级原文编辑同一草稿，未知字段按语义保留；TOML 注释和排版不保留。
- 共通表单仅保留上表思考、搜索、更新、署名及历史大小选项；已存在的更新渠道、记忆、语言、隐私等其他字段仍按原文保留。
- 首页和供应商设置每行展示一个供应商；编辑供应商页直接展示完整配置，使用当前生效模型（未启用的供应商回退默认模型）、当前草稿和已保存共通模板，没有预览模型选择和展开按钮。
- 列表和完整配置中的 API Key 统一显示前后缀脱敏标识；编辑器输入框默认隐藏内容，点击眼睛可按需查看已保存的完整密钥，只查看不算修改。
- 首页的 Base URL 与模型各占一行，长模型名可换行展示完整，不显示 API Key；设置页保留脱敏 Key。
- 历史大小与单位同一行展示；输入框、输入框组、下拉框和默认按钮统一使用官方 radix-nova 的 32px 默认高度。
- 不管理系统、终端或启动环境变量；Claude 的 `env` 仅指 `settings.json` 内的字段。
- 不提供任意上下文数值、压缩阈值、输出 token 上限或额外查询参数。已有范围外配置保留。

官方全部原生配置见 [字段索引](tool-configuration-field-index.md)，索引中的其他字段不代表应用提供相应控件。
