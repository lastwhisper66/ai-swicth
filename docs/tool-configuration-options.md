# 配置功能执行计划

更新日期：2026-10-25。状态：本计划功能已实装；兼容边界及已完成、待完成的验证见 [实现与验收记录](tool-configuration-implementation.md)。

本计划以用户最后一次逐项指定的内容为准，替代此前的推荐清单与 P0／P1 划分。下列全部项目属于本次实施范围；先后顺序只是开发顺序，不表示把部分项目留到后续。简表见 [本次字段清单](tool-configuration-fields.md)。

## 页面和操作边界

| 配置位置                  | 本次管理内容                                                                                               |
| ------------------------- | ---------------------------------------------------------------------------------------------------------- |
| 供应商侧 → 连接配置       | API 地址、鉴权、自定义模型 API 请求头；Codex 的 WebSocket 兼容能力                                         |
| 供应商侧 → 模型列表和路由 | 同一供应商多个模型、默认模型；Claude Code 的默认 Opus／Sonnet／Haiku 路由与子代理模型                      |
| 供应商侧 → 模型选项       | Claude Code 仅提供 1M 复选框；Codex 提供 1M、思考强度、Fast mode、计划模式思考强度、思考摘要和回复详细程度 |
| 共通配置页 → Claude Code  | 思考强度、工具搜索、网络搜索、网络拉取、隐藏 AI 署名                                                       |
| 共通配置页 → Codex        | 网络搜索、启动时检查更新、历史文件大小                                                                     |

只管理目标 `settings.json`、`config.toml` 及应用自身的供应商库、共通模板和备份。允许写入 `settings.json` 内的 `env` 字段；不管理系统、用户、终端或启动环境变量，不提供外部环境变量引用选项。自定义请求头直接输入名称和值。

Claude 的思考强度仅在共通页设置，其他模型选项在供应商侧设置；工具和搜索选项不在供应商侧设置，也不提供供应商兼容覆盖。切换供应商或模型沿用共通设置，保存共通配置保留供应商与模型选择。保留现有高级原文入口及不属于本次管理范围的原有配置。

首页和供应商设置统一为横向列表，每行一个供应商。首页保留模型选择与应用；供应商编辑页直接展开完整配置，使用当前生效模型（未启用的供应商回退默认模型）和当前草稿，不提供预览模型选择和展开按钮。API Key 在列表及配置文本中按相同规则保留前后缀，输入框默认隐藏内容；点击眼睛可在输入框按需显示已保存的完整密钥，只查看不算修改。

## Claude Code 实施清单

| 功能                          | 配置文件映射                                                                                          | 界面位置            |
| ----------------------------- | ----------------------------------------------------------------------------------------------------- | ------------------- |
| 一个供应商多个模型            | 应用保存模型列表和默认模型，仅填写模型名，应用选中模型时写入 `model`                                  | 供应商侧 → 模型列表 |
| 启用 1M 长上下文              | 复选框控制末尾 `[1m]` 后缀，直接输入后缀也可识别；不按模型名禁用                                      | 供应商侧 → 模型     |
| 思考强度                      | `effortLevel`，并同步当前模型的 `modelSettings.<model>.effortLevel`；仅 low / medium / high / xhigh   | 共通配置            |
| MCP Tool Search               | `env.ENABLE_TOOL_SEARCH`                                                                              | 共通配置            |
| Web Search 权限               | `permissions.allow`／`ask`／`deny` 中的 `WebSearch`                                                   | 共通配置            |
| Web Fetch 权限                | `permissions.allow`／`ask`／`deny` 中的 `WebFetch`                                                    | 共通配置            |
| 隐藏 AI 署名（一个开关）      | 同时处理 `attribution.commit`、`attribution.pr`、`attribution.sessionUrl`                             | 共通配置            |
| 自定义 API 请求头             | `env.ANTHROPIC_CUSTOM_HEADERS`                                                                        | 供应商侧 → 连接配置 |
| 默认 Opus／Sonnet／Haiku 路由 | `env.ANTHROPIC_DEFAULT_OPUS_MODEL`、`ANTHROPIC_DEFAULT_SONNET_MODEL`、`ANTHROPIC_DEFAULT_HAIKU_MODEL` | 供应商侧 → 模型路由 |
| 子代理模型                    | `env.CLAUDE_CODE_SUBAGENT_MODEL`                                                                      | 供应商侧 → 模型路由 |

表中的 `env.*` 均是 JSON 字段路径，不是对系统或终端环境的操作。共通表单仅提供思考强度、工具搜索、网络搜索、网络拉取和隐藏 AI 署名，原有的其他字段仍通过高级原文保留。Claude 不再提供模型显示名称、Fast 和自动压缩控件；旧预设的思考强度、Fast 和自动压缩选项不再应用，原有工具文件中的 Fast 和压缩配置保留。

### 隐藏 AI 署名的统一行为

界面只提供“隐藏 AI 署名”一个开关，不单独增加提交、PR、会话链接署名的设置入口。启用时，一次性生成并校验：

```json
{
  "attribution": {
    "commit": "",
    "pr": "",
    "sessionUrl": false
  }
}
```

原生版本支持等效的整体关闭写法时，可由适配器选择兼容格式，但语义必须同时覆盖三类署名。旧版不能识别的字段不能直接写入；版本兼容结论应在实现时核对。已有部分隐藏、部分自定义的配置显示“部分隐藏／自定义状态”，读取时不自动改写。

关闭开关或恢复默认时，恢复接管前的署名设置；原本没有设置时清除本应用生成的覆盖。不强制写入新的 AI 署名文本，也不覆盖其他 `attribution` 子字段。

## Codex 实施清单

| 功能               | 配置文件映射                                             | 界面位置            |
| ------------------ | -------------------------------------------------------- | ------------------- |
| 一个供应商多个模型 | 应用保存模型列表和默认模型，应用选中模型时写入 `model`   | 供应商侧 → 模型列表 |
| 启用 1M 长上下文   | 固定生成 `model_context_window = 1000000`                | 供应商侧 → 模型     |
| 思考强度           | `model_reasoning_effort`                                 | 供应商侧 → 模型     |
| Fast mode          | `service_tier = "fast"`，按版本配合 `features.fast_mode` | 供应商侧 → 模型     |
| 自定义 API 请求头  | `model_providers.<id>.http_headers`                      | 供应商侧 → 连接配置 |
| Web Search         | `web_search`                                             | 共通配置            |
| 启动时检查更新     | `check_for_update_on_startup`                            | 共通配置            |
| 计划模式思考强度   | `plan_mode_reasoning_effort`                             | 供应商侧 → 模型     |
| 思考摘要           | `model_reasoning_summary`                                | 供应商侧 → 模型     |
| 回复详细程度       | `model_verbosity`                                        | 供应商侧 → 模型     |
| WebSocket 兼容能力 | `model_providers.<id>.supports_websockets`               | 供应商侧 → 连接配置 |
| 历史文件大小       | `history.max_bytes`                                      | 共通配置            |

Codex 的 1M 只提供“请求 1M／恢复工具默认”，不提供任意上下文数值或 200K 限制。Claude 使用复选框添加或移除 `[1m]`。取消 1M 或恢复默认不等于强制降低容量，也不附带写入自动压缩阈值。模型及网关是否实际支持 1M 或 Fast，需要与已写入配置的状态区分，不通过付费 API 探测。

## 控件和兼容行为

| 类型                  | 实现要求                                                                                                                                                      |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 多模型                | 每条记录有稳定 ID、API 模型 ID 和独立选项；Claude 名称由模型名生成，Codex 可单独填写显示名称。每个供应商、每个工具选择一个默认模型                            |
| 模型选择与应用        | 供应商侧编辑模型；工具首页可选择已有模型并点击应用。保存模型不立即修改目标文件；应用时一并写入该供应商连接和所选模型的选项                                    |
| 模型选项              | Claude 仅保留 1M 复选框，共通思考强度固定四个选项、不按模型名限制；Codex 按版本和官方模型支持的级别提供选项                                                   |
| Tool Search           | 一个模式选择项：工具默认／启用／禁用／自动；映射为不写入、`true`、`false`、`auto`。不把“默认”误认为 `auto`                                                    |
| Web Search／Web Fetch | Claude 提供默认／允许／每次询问／禁止，按对应工具增删权限规则，保留其他规则；已有通配符或更高层规则冲突时明确提示。Codex 按该版本支持的 `web_search` 模式显示 |
| 更新                  | Codex 仅管理启动时检查 CLI 更新，不控制桌面应用或外部包管理器更新。                                                                                           |
| 历史大小              | Codex 历史文件大小使用易读单位输入并转换为 bytes。                                                                                                            |
| 请求头                | 使用名称／值行式编辑器，校验名称、重复项、非法换行和鉴权冲突；不假定可以覆盖所有 SDK 自动生成的头。默认脱敏，支持保留／替换／删除，不能把脱敏值写回文件       |

“模型选项在界面按模型保存”与“目标工具的原生作用范围”分别说明。部分原生字段作用于整个当前会话，应用在切换预设时更新对应字段，不承诺工具原生支持对每个子模型独立生效。

### 配置合并和数据迁移要求

每个原生字段只有一个管理位置。共通模板目前可能包含本次要迁为供应商或模型选项的字段，须先显示归属和冲突，再迁到对应记录；不能把当前供应商的 Header 自动复制到全部供应商。

应用时组合“供应商连接＋当前模型预设＋该工具共通配置”，按字段合并；`env`、`features`、`modelSettings` 等对象不能整块覆盖。Codex 切换到默认选项时恢复接管前的强度和 Fast 配置。Claude 切换后沿用共通强度，同步当前模型级条目并保留其他子字段，旧模型预设的强度不能恢复覆盖它。只清理由应用管理的旧覆盖，保留未接管的原有配置。

扩展供应商数据和云端迁移格式版本，兼容旧版单模型备份；新格式必须包含全部模型、默认模型、路由、Header、选项和共通设置，不能静默丢弃。新增 Header 值和署名接管前状态等敏感内容继续按现有本地存储及云端加密规则处理；普通预览、日志和错误中遮蔽 Header 值。现有脱敏逻辑需补齐 `ANTHROPIC_CUSTOM_HEADERS` 及任意命名的 Header。

延续写前备份、外部修改检测、原子替换和失败回滚。目标文件和共通模板一起备份恢复；如增加已应用模型或署名恢复状态，也与对应操作同步。恢复工具文件不暗中回退整个供应商库。只有用户主动应用、保存并应用共通配置或恢复时才修改目标文件，完成后提示新建或重启对应会话。

### 人工验收

1. 两个工具分别创建同一供应商的多个模型，编辑、删除、设默认、切换并重启应用，核对持久化及原生文件。
2. 逐项操作本计划的全部开关和选择项，核对准确字段；1M 不重复拼接后缀，不出现自定义上下文或压缩阈值输入。
3. Codex 同一模型 ID 的两个预设可使用不同强度与 Fast 配置，切换不残留旧选项。Claude 仅填写模型名，1M 勾选添加一次 `[1m]`，取消移除；自定义别名可勾选，手动输入后缀可识别。共通强度只有 low / medium / high / xhigh，保存并切换后模型级条目沿用所选强度，其他子字段保留；路由及子代理模型按保存值生成。
4. 隐藏 AI 署名只操作一个开关，三类署名同时隐藏；已有部分自定义状态正确显示，关闭或恢复能还原原有设置。
5. 切换供应商／模型不改变共通设置，保存共通配置不改变供应商／模型；修改任一工具不影响另一个工具。
6. Header 默认脱敏且能保留、替换、删除；不同供应商互不串用；预览、错误和日志不泄露值。原文中的未知字段及无关权限规则仍然保留。
7. 检查旧单模型数据、旧云端备份、新格式云端往返，以及本地恢复后的配置和已应用状态一致性。
8. 检查文件不存在、格式损坏、无权限、被外部修改、工具版本未知或字段不支持时的反馈；全程使用临时目录和占位密钥，不调用付费 API，不修改系统／终端环境，不编写自动化测试或临时测试脚本。
